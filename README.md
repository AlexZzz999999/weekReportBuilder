# 周报工坊

一个纯本地运行的周报编辑器。使用前由用户选择电脑目录，周报数据会直接
写入该目录中的 `周报工坊数据.json`，不需要数据库、账号或云服务。

## 本地启动

首次使用：

```bash
npm install
npm run dev
```

打开终端提示的地址（默认是 `http://localhost:3000`）即可使用。

后续启动只需要：

```bash
npm run dev
```

## 已支持

- 默认提供风险点、管道需求、运营需求、待办公共事项四类周报内容
- 可新增、重命名、换色、排序或删除整张周报表格
- 表格内直接编辑、增删记录
- 每个分类单独自定义列名、列类型和列顺序
- 状态枚举支持新增、重命名、分类、排序和删除
- 使用前强制选择或确认电脑目录
- 自动保存到所选目录中的 JSON 数据文件
- 页面内可随时更换数据目录
- 一键生成正式周报
- 复制到邮件或群聊
- 打印或导出 PDF

## 数据目录说明

- 推荐使用最新版 Chrome 或 Edge
- 目录访问功能要求 HTTPS 或 `localhost`
- 页面打开后直接选择电脑目录，不读取浏览器中的历史授权
- 周报正文保存在所选目录的 `周报工坊数据.json`
- 每次打开都会要求重新选择目录
- 更换电脑时复制该 JSON 文件即可迁移数据
- 点击左下角“恢复示例数据”会覆盖当前内容
