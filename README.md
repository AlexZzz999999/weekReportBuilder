# 周报工坊

一个纯本地运行的周报编辑器。数据保存在当前浏览器的 `localStorage` 中，
不需要数据库、账号或云服务。

## 本地启动

首次使用：

```bash
npm install
npm run dev
```

打开终端提示的地址（默认是 `http://localhost:3000`）即可使用。

后续启动只需要：

```bash
npm run dev
```

## 已支持

- 默认提供风险点、管道需求、运营需求、待办公共事项四类周报内容
- 可新增、重命名、换色、排序或删除整张周报表格
- 表格内直接编辑、增删记录
- 每个分类单独自定义列名、列类型和列顺序
- 浏览器本地自动保存
- 一键生成正式周报
- 复制到邮件或群聊
- 打印或导出 PDF

## 本地数据说明

- 数据只保存在使用该工具的浏览器和电脑上
- 清理浏览器站点数据会同时清除已填写内容
- 点击左下角“恢复示例数据”会覆盖当前内容
